# Structurally Impossible

Allows placed prefabs to be flagged to ignore stability checks.

This requires the Unstrippable mod to also be installed on the host\server to persist through world loading. 

Vanilla compatible if Unstrippable is installed on host\server. While they will not be able to place the flagged prefabs, they will correctly skip stability checks.

### Installation
Download latest and extract the dll from the zip file into ``[GameDirectory]\Bepinex\plugins``
