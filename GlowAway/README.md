# Glow Away

Customise the scale and intensity of the weapon quality glow.

The intensity is the color pulled from the individual weapons weapons intensityColorGradient.
Scale is how much glowy it is.

There is some particle effect caching going on sometimes, so after you change the values, they might not show up right away without a restart.
